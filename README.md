# Console-UNO-Game
A complete **two-player UNO card game** built in C++ for the console with colorful output and full game mechanics.

## Features

- Classic UNO rules implementation
- Special Cards: Skip, Reverse, Draw 2, Wild, Wild Draw 4
- Color selection for Wild cards
- UNO calling system with penalty
- Game logging and score history
- Colorful console interface using Windows API
- Save game results to file

## How to Play

1. Compile the program
2. Run the executable
3. Choose options from the main menu
4. Follow on-screen instructions during gameplay

## Controls

- Enter numbers to select cards or options
- Type `Y/N` for confirmations

## Build & Run

```bash
g++ UNOgame.cpp -o UNO.exe
UNO.exe
